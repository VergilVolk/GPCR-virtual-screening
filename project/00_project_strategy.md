# CHRM4 别构 PAM 设计 — 项目总体策略 v2.0 (2026-08-22)

> **赛道三**：离子通道、GPCR 等药靶的小分子药物虚拟筛选
> **靶点**：人源 M4 毒蕈碱乙酰胆碱受体（CHRM4）**正性别构调节剂（PAM）**
> **数据**：`../CHRM4_PAM_Modeling_Handoff_v1.0/`（FROZEN 2026-08-16，430+ 阳性 / 66 严格非活性，全部 human M4 PAM 功能效力）
> **结构**：PDB **7TRQ**（M4–iperoxo–VU0467154–Gi1，2.5 Å cryo-EM，正构+别构双配体）
> **环境**：纯 CPU Windows（Python 3.13 + RDKit + sklearn + torch-CPU）

## 0. 一句话定位

**用「PAM 效力感知的多证据虚拟筛选（PEAM-VS）」回答一个所有现成工具都答不了的问题：给定一个分子，它是不是（或有多强地是）一个 M4 别构 PAM？**

> 旧版策略与 MRGPRX1 时代文档已归档至 `archive_mrgprx1/`（含 8DWG/8HJ5、ML382、ROC AUC=0.44 等，仅作对照溯源，**不是**当前项目状态）。

## 1. 核心科学问题（团队共识）

> hyw：*"现在最大的困难是：一个东西怎么确定一个分子是不是 PAM。没有 baseline，也没有现成模型。"*

这正是本项目的靶心。拆成三个可计算的子问题（即三个 QSAR 任务）：

| 任务 | 问题 | 目标量 | 数据集 | 用途 |
|------|------|--------|--------|------|
| **Task A 回归** | 这个分子作为 M4 PAM 有多强？ | `pEC50`（数值，越高越强） | `modeling_potency_exact_calcium.csv`（430 分子，全钙流 FLIPR，探针=乙酰胆碱） | 给候选分子**预测效力** |
| **Task B 分类** | 这个分子到底是不是 PAM？ | 0/1（PAM vs 实验确认非活性） | `modeling_pam_vs_inactive.csv`（463 阳 / 66 阴） | 严格**识别** PAM |
| **Task C 阈值** | 10 µM 内有没有 PAM 效力？ | 0/1（≤10 µM vs 未达阈值） | `modeling_threshold_10uM.csv`（463 / 70） | 高通量**预筛** |

**这就是"检验"环节的引擎**——先用数据训练（右线产物），再用于判断生成分子（左线产物）。

## 2. 双线思路（对齐团队手绘流程图）

```
┌─────────────────────────── 左线: 靶点结构生成 ───────────────────────────┐
│  CHRM4 结构(7TRQ) → 扩散模型生成新分子(DiffSBDD/TargetDiff 类)           │
│  ⚠️ 难点: 扩散模型逐步去噪的损失函数需自定义, 无现成 recipe; 纯CPU不可跑  │
│  → 当前策略: 该线作为"远期+创新叙事", 由右线生成分子 + 结构筛选替代      │
└───────────────────────────┬───────────────────────────────────────────────┘
                            ▼ 汇合: 检验 (PEAM-VS 多证据引擎)
┌─────────────────────────── 右线: 数据迁移学习 ────────────────────────────┐
│  PubChem 类药语料 → 预训练(SMILES LSTM, 学化学语法)                      │
│  → CHRM4 PAM 阳性 → 微调(把分布掰向 PAM 化学型)                          │
│  → 采样生成"照着已有PAM的样子"的新分子 ✅ 已实现(smiles_lstm_gen.py)      │
└───────────────────────────┬───────────────────────────────────────────────┘
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │  PEAM-VS 检验引擎 (纯CPU可跑):                                      │
   │  ① QSAR 预测: Task A pEC50 + Task B/C 分类 (数据证据)               │
   │  ② 结构证据: Vina 对接入 7TRQ 别构口袋 (VU0467154 位点)             │
   │  ③ 药效团证据: 多亚位点药效团/IFP 匹配 (M4 别构 vestibule)         │
   │  ④ 成药性: 类药性 + SAscore + 与已知阳性相似度                      │
   │  → 集成排序 → Top 候选 PAM 分子                                     │
   └─────────────────────────────────────────────────────────────────────┘
```

## 3. 创新点（论文/答辩的"卖点"）

1. **首个干净的 human-M4 PAM 功能效力开放数据集**（430 阳性 + 66 严格非活性，全 human、全功能终点、EC50/pEC50 口径统一、分子级隔离）——已冻结 v1.0
2. **PAM 效力 ≠ 亲和力的双靶点实证**：MRGPRX1 别构（ROC AUC=0.44，归档）证明传统对接打分对别构 PAM 失效；CHRM4 上复现同一现象（本阶段任务），把"打分失效"做成**通用结论**而非单靶点个案。
3. **PAM 效力感知生成（迁移学习 + 微调）**：把生成目标从"高亲和力"改为"像已知 PAM"，纯 CPU 可复现（REINVENT 式 LSTM）。
4. **多亚位点药效团重打分**：M4 别构 vestibule 可能存在多个子位点（VU 类 vs LY 类化学型），多药效团 A+B 可把 MRGPRX1 基准 AUC 从 0.44 提到 1.0（归档实验 9）——在 CHRM4 上复现并推广为「探针依赖性感知」建模。
5. **探针依赖性分析**：冻结数据带 `orthosteric_agonist` 列（乙酰胆碱等），可数据化检验"PAM 对探针的选择性"——对应 PPT 方案 B 的计算实现。

## 4. 技术栈与数据

### 4.1 冻结数据视图（勿改，主键 `canonical_molecule_id`）

| 文件 | 用途 | 规模 |
|------|------|------|
| `modeling_potency_exact_calcium.csv` | **Task A 主回归**（钙流 FLIPR，探针=乙酰胆碱） | 430 分子，pEC50 5.06–8.10 |
| `modeling_potency_exact.csv` | 扩展回归（含 GIRK/thallium，需 assay 协变量） | 460 分子 |
| `modeling_pam_vs_inactive.csv` | **Task B** 严格二分类 | 463 阳 / 66 阴 |
| `modeling_threshold_10uM.csv` | **Task C** 阈值分类 | 463 阳 / 70 阴 |
| `compounds.csv` | 规范 SMILES / InChIKey | 930 行 |
| `assays.csv` | assay 元数据（含 `orthosteric_agonist` 探针信息） | 110 行 |

**铁律**：最小隔离单元 = `canonical_molecule_id`；禁止行级随机划分；推荐骨架划分（防近缘物泄漏）。

- 配体：**IUI = VU0467154**（PAM，29 重原子，别构）、**IXO = iperoxo**（正构激动剂）
- 别构口袋 = VU0467154 结合位点（M4 胞外 vestibule），下一步做接触残基分析 + 盒子定义 + redocking 验证

## 6. 风险与对策

| 风险 | 对策 |
|------|------|
| 430 分子 QSAR 泛化有限 | 骨架划分诚实报告；多模型集成 + 相似度近邻校准；强调"数据稀缺本身是边界" |
| Vina 对别构 PAM 失效 | 这是**卖点不是 bug**——实证后用法转向：药效团/QSAR 为主，Vina 只做位置证据 |
| 纯 CPU 跑不动扩散模型 | 右线 LSTM（已实现）+ 片段生成顶上；扩散模型作为"方法学讨论+未来工作" |
| 时间紧（9-05 摘要） | 全部计算 1-2 天内跑完；摘要先发框架+初步结果，10-04 前补全 |
