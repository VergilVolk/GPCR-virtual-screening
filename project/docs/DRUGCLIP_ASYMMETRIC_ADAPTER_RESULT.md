# DrugCLIP 非对称分子适配器：阶段结果

更新时间：2026-09-26

## 1. 问题与方法

原始 DrugCLIP 同时使用预训练分子编码器和三维口袋编码器。现有实验显示，它能保留跨 GPCR 的一般结构信息，但对 M1–M5 这类高同源受体的亚型选择性分辨不足。

本轮方法不重新训练口袋编码器，而是：

1. 冻结 DrugCLIP 三维口袋 embedding；
2. 用 Morgan/ECFP 分子指纹训练一个 `2048→128` 的线性分子适配器；
3. 采用同一分子在两个受体亚型之间的活性顺序构造 triplet/ranking loss；
4. 训练时完全排除待测受体口袋和待测分子；
5. 只在非 M4 校准集选择指纹半径，然后一次性评价冻结 M4 集。

该方法回答的是“分子更偏好哪个毒蕈碱受体亚型”，不是 PAM 功能或效力预测。

## 2. 严格数据切分

- 五亚型 target-LOSO：每折完全留出一个受体口袋；测试分子从该折训练集中全部删除。
- 训练/测试分子重叠为 0；Murcko 骨架重叠为 5.5%–23.6%。
- 冻结 M4 面板：102 个未见分子、153 个 M4-vs-其他亚型配对；训练不含 M4 口袋。
- 指纹选择只使用 33 个非 M4 未见分子构成的 54 个配对；M4 标签不参与选择。

## 3. 主要结果

| 方法 | 五亚型 LOSO 宏准确率 | 完整 M4 折 | 冻结困难 M4 面板 |
|---|---:|---:|---:|
| DrugCLIP triplet | 55.4% | 53.3% | 66.0% |
| ECFP2 → 冻结口袋 | 71.8% | 84.3% | 66.7% |
| ECFP3 → 冻结口袋 | **73.0%** | **87.5%** | **68.6%** |
| ECFP+DrugCLIP 联合适配器 | 72.9% | 80.2% | 65.4% |

完整 M4 折中，ECFP3 相对 DrugCLIP 的分子成簇 bootstrap 95% CI 为 `+28.2` 至 `+39.9` 个百分点。冻结困难 M4 面板中，ECFP3 相对 DrugCLIP 的差值为约 `+2.6` 个百分点，但 95% CI 为 `-6.5` 至 `+11.0`，尚不显著。

## 4. 消融与失败结果

- 直接把 DrugCLIP 分子 embedding 作为 ECFP 残差，只在 M4 完整折小幅改善，但宏平均下降。
- 可训练的 ECFP+DrugCLIP 拼接适配器改善了部分亚型，却降低完整 M4 折和冻结 M4 面板，存在目标依赖的负迁移。
- 将 ECFP3 适配器直接用于 B2AR/CCR2/M2R/M4R 的跨家族 target-LOSO 时，宏 Recall@1 接近 0；家族内适配器不能代替跨家族 foundation model。
- DrugCLIP 家族路由 + 毒蕈碱局部适配器将不平衡总体 Recall@1 从 35.8% 提高到 67.4%，但宏 Recall@1 仅从 41.3% 到 42.3%，置信区间跨零，并严重损害 M2。
- 独立校准集上的两特征门控虽然 scaffold-OOF 为 86.0%，跨数据集迁移后宏 Recall@1 降至 38.2%；该门控被否决。

## 5. 当前可成立的创新与边界

可成立的算法点是“非对称、家族条件化的 DrugCLIP 适配”：保留预训练三维口袋空间，用化学监督重建高同源亚型所需的分子映射。它显著优于直接微调 DrugCLIP 的投影层，并通过未见口袋、未见分子和骨架审计。

当前不能宣称：

- 通用 GPCR SOTA；
- PAM 身份或 PAM 效力预测；
- ECFP3 在冻结 M4 面板上显著优于所有基线；
- 分层路由已经解决跨家族检索。

下一步最有价值的验证是增加独立毒蕈碱选择性数据集，或在预先冻结的新受体家族上复用同一协议；不应继续在现有 153 对 M4 面板上调参。

## 6. 对现有候选的选择性审计

三种子 ECFP3 适配器对 200 个 PACER 候选进行了 M1–M5 排序，24 个候选的 M4 排名第一。原 12 个多证据 shortlist 中，仅 `PACER0054` 同时满足原综合排名靠前与 M4 亚型选择性支持：原 fusion rank 为 8，选择性 rank 为 6/200，M4-vs-次优亚型 margin 为 `0.0854`，三种子标准差为 `0.0064`。

该结果仅将 `PACER0054` 提升为后续验证优先级较高的候选；不证明其能结合 M4、具有别构作用或增强 ACh 响应。
