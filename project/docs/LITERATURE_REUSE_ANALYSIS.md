## 一、四篇论文逐篇分析

### 1. Nguyen et al. 2025, PNAS —— A1 腺苷受体 PAM 的基于结构发现

**这是与我们任务最同构的一篇**：同样是"基于结构发现 GPCR PAM"，而且是顶刊正刊。

**核心问题**：A1R 的 PAM 结合在**面向脂质双分子层的胞外螺旋间（extrahelical）口袋**，而传统 docking 假设受体周围是水环境（ε=80），对这个口袋描述很差。

**方法/创新点**：
1. **膜感知对接（membrane-aware docking）**——两种实现：
   - 隐式膜：口袋周围介电常数 ε=80 → ε=2（模拟膜疏水核心），配体完全去溶剂化；
   - 显式膜：把 MD 模拟得到的脂双层构象直接保留在 docking 里（200 个快照）。
2. **MD 集合对接（ensemble docking）**：用配体结合复合物的 MD 快照做 docking，选富集最好的 5 个快照用于前瞻筛选。**关键数字：LogAUC 从 15（cryo-EM 单结构）提升到 39（集合）**，提升约 2.5 倍。
3. **属性匹配 decoy 基准**（DUD-E 协议，40-50 个 decoy/活性物）+ 实验确认的非活性物（66 个），用 adjusted LogAUC 度量。
4. **理化性质先验**：比较 PAM 与非活性物的物理化学性质，发现 **PAM 更亲脂**，据此把筛选库过滤为 LogP 2.5–4.5。
5. **超大库漏斗**：ZINC 1.6 亿分子 → 刚性受体 DOCK3.7 → 前 0.5% → **关键残基氢键过滤**（必须与 S2466.47 侧链和 L2767.41 骨架形成氢键）→ 2D 相似性聚类（ECFP4, Tc≥0.5，每簇只留打分最好的代表）→ 前 1000 簇人工检查 → 26 个化合物。
6. **结构引导优化**：子结构搜索（2-aminothiazole，6729 个）+ 相似性搜索（Tc≥0.5，333 个）→ 重新对接 → 22 个类似物 → SAR 合并取代基 → 合成 7 个 → 54/56 活性提升。
7. **药理学的"干净 PAM"概念**：用变构三元复合物模型（pKB 亲和力、logα 结合协同）+ 操作模型（logτB 内在效力、logαβ 功能协同）量化；**理想 PAM 是"低变构激动"**（logτB ≤ 0，即不给正位激动剂时自身不激活受体）。
8. **选择性验证**：54/56 对其他腺苷受体亚型（A2A/A2B/A3）和 M2 受体无活性。

**对我们的启示**：命中率 11.5%（26 选 3），且找到了结构新颖的 scaffold（12 号化合物对已知最近分子 Tc 仅 0.4）——说明"打分失败"是真实存在的普遍现象，连 PNAS 的正刊命中率都只有 11.5%。我们完全可以直接复用：亲脂性过滤、关键残基（我们的 TYR439 hub）接触硬过滤、聚类去冗余、clean-PAM 药理框架。

### 2. Bhattarai, Wang & Miao 2020, BBA —— A1AR 变构调节剂回测集合对接

**核心问题**：静态晶体结构 docking 失败；变构位点（ECL2）高度柔性。

**方法/创新点**：
1. **GaMD（高斯加速分子动力学）**：加谐波 boost 势，无需预设集体变量，可用累积量展开重加权恢复自由能。
2. **集合构建**：GaMD 轨迹（3×300 ns）每 0.2 ps 取帧 → CPPTRAJ 层次聚类 → **10 个代表性受体构象簇**。
3. **能量重加权打分（核心创新）**：`BE_i = E_dock,i + PMF_i`，即每个配体对每个构象簇的对接分 + 该簇的重加权自由能（PMF）。60 项指标中 29 项（48%）因重加权而改善。
4. **BEmin vs BEavg 排序**：多数情况下平均结合能 BEavg 优于最小结合能 BEmin。
5. **柔性 docking >> 刚性 docking**：侧链柔性很关键，EF(5%) 从 0.0 → 0.8，EF'(5%) 最高到 8.33。
6. **Holo（PAM 结合）集合优于 Apo**：VCP171 结合的 A1R GaMD_Dual 集合最佳，AUC 0.60 vs cryo-EM 0.53，EF'(5%) 8.33 vs 2.88。
7. 基准集：25 个已知 PAM + 2475 个 DUD-E decoy。

**对我们的启示**：这是"集合对接 + 自由能重加权"的原型。我们 CPU 环境跑不了 GaMD，但 **2026 年那篇把 M4R 的 GaMD 集合簇和逐簇 Vina 打分直接开源了**——我们不需要跑模拟，直接复用他们的构象集合和打分，就能实现 BEmin/BEavg 重加权排序。

### 3. Thompson & Miao 2026, bioRxiv —— GPCR 变构调节剂对接协议基准测试

**这篇把我们靶点 M4R 作为四个基准靶点之一，是最直接的"参考答案"。**

**基准设置**：M2R / **M4R** / CCR2 / β2AR × 4 个程序（Glide HTVS、AutoDock Vina、DOCK3.8、Boltz-2）对 PDB 单结构和 GaMD 集合，用 ASD2023 变构调节剂库 + 属性匹配 decoy（50:1，LUDe 协议）测 EF/EF'/AUC/logAUC。

**M4R 关键结果（直接影响我们）**：
- M4R 库：**2314 个 PAM + 115,643 个 decoy**；decoy-to-active 平均 Tc = 0.100。
- **Vina 在 M4R 早期富集极差**：PDB EF(0.5%)=0.778，EF'(0.5%)=0.589（≈随机水平）；AUC ~72-73%（全局区分尚可但早期富集不行）。——**这正好解释了我们在 7TRQ 上测到 Vina AUC 0.33 的现象**：不是我们做错了，是 Vina 对 M4 变构位点本来就弱。
- **Glide 集合对接 BEmin 是 M4R 最优协议**：EF(0.5%) 11.5 → 20.4，EF'(0.5%) 10.4 → 21.8，logAUC 11.6 → 16.1。
- **M4R 自由能景观决定重排序策略**：M4R 的 cluster 00 占 ~80% 帧、自由能梯度陡（0–5.22 kcal/mol），**应选 BEmin**（加一个 cluster 就让 BEavg 的 EF(0.5%) 掉 9.8 分）。
- **单簇替代**：被单一低能态主导的靶点，**只用 cluster 00 一个构象就可能达到或超过全集合性能**——成本极低。
- **共识策略**：取 BEmin 与 BEavg 各自 top 百分位命中的**并集**，可最大化命中化学多样性。
- **程序特异性 scaffold 偏好**：Glide/Vina 偏好 F2 家族（高相似），DOCK3.8 偏好 F1（多样），Boltz-2 覆盖最广——单程序有系统性 scaffold 偏差。
- **Boltz-2（DL 共折叠）早期富集弱**：对 GaMD 模板不敏感，应作为补充而非主筛选工具。

**对我们的启示**：
- M4R 的"标准答案"协议 = **GaMD 集合 + BEmin 重排序**；他们已开源 M4R 集合簇、PMF 和逐簇 Vina 打分。
- 我们的几何接触证据（AUC 0.87）恰好扮演论文里"第二个打分函数"的角色——用共识/并集逻辑与 Vina 互补，这正好接上他们"最大化 scaffold 多样性"的建议。
- 我们的 n=20 基准太小，**应该用他们开源的 2314 PAM + 11.5 万 decoy 做大样本基准**，把"打分失败"从 20 个分子的观察升级为千人规模的统计结论。

### 4. Miao & McCammon 2016, PNAS —— M2 毒蕈碱受体的分级激活与自由能景观

**核心问题**：GPCR 如何区分不同效力（inverse/partial/full agonist）的配体。

**方法/创新点**：
1. GaMD 无约束增强采样 + 自由能计算（约 19 μs 总模拟）。
2. **几何反应坐标的 2D PMF**：酪氨酸盖（Tyr1043.33–Tyr4036.51–Tyr4267.39 三角形周长）、胞外前庭宽度（Tyr177ECL2–Asn4106.58 距离）、G 蛋白偶联位点开关（Arg1213.50–Thr3866.34 距离）——用 Cα 距离定义激活态。
3. 单条模拟中观察到部分激动剂 ARC 的**解离-再结合**（4 次解离、3 次结合），DBSCAN 聚类 + 重加权得到结合/解离通路。
4. **关键结构概念**：M2 变构位点在胞外前庭，位于正位点上方约 15 Å；前庭存在两个低能结合位点（正位 + 前庭），与我们的"双口袋 + 8.03 Å 配体间距 + TYR439 hub"发现结构上同源。

**对我们的启示**：他们用几何距离刻画受体状态，我们已经在做类似的事（hub 接触、双口袋最短路径、配体-配体距离 8.03 Å）。我们的"正位-变构偶联几何证据"可以顺着这个框架升级为"**激活态几何描述子**"：不只看配体-受体接触，还看配体-配体（iperoxo↔VU0467154）通过 hub 残基的间接耦合。

## 三、决策提案

**主推（R1 + R2 + R3 组合）——"文献验证过的 M4R 基准升级"**：

1. 下载 Miao 2026 开源的 M4R 数据（**已下载**）；
2. 用他们的逐簇 Vina 打分复现 BEmin/BEavg/PDB 富集（纯分析，验证我们理解对了）；
3. 把我们的几何接触 + hub 接触特征在这套数据上重测——需要给子集重对接（约 200 PAM + 200 decoy 到 cluster 00 + PDB，2 个构象 ≈ 800 次对接，CPU 几小时可完成），或者只做 1:1 抽样；
4. 我们的候选化合物跑 2-3 构象集合对接 + BEmin 重排序；
5. 论文方法论章节升级为"**集合对接 + 几何证据共识**"，创新叙述变为：*发现 Vina 对 M4 变构位点早期富集系统性失败（与大样本文献结论一致）→ 提出几何接触证据作为低成本第二打分函数 → 共识并集最大化 scaffold 多样性*。

**叙事升级效果**：从"我们做了个机制分析"升级为"**我们在文献验证的基准上提出并验证了替代打分证据**"，且有 PNAS/2026 基准两条独立文献支撑，创新性从"够用"变"可辩护"。

**备选**：如果时间不够跑 800 次对接，直接 R2（零计算）+ R4/R5（现有数据）也能形成"文献复现 + 机制证据"的组合。
