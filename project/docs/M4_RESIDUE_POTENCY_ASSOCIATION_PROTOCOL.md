# M4 PAM 残基—功能效力关联协议

冻结日期：2026-08-30

## 目的

检验7TRQ、7TRP、7TRS静态pose中，是否存在跨药化系列仍与ACh功能pEC50相关的单残基接触信号。该分析寻找可证伪机制线索，不把相关性解释为因果或PAM身份。

## 防捷径规则

1. pEC50在每个`source_component`内中心化，去除文献/系列基线；
2. 原子对接触数除以配体重原子数，降低分子大小偏差；
3. 同时分析各状态绝对特征和`7TRS - mean(7TRQ,7TRP)`状态差；
4. 显著性用系列内标签置换5000次，保持每个系列的化学组成和效力分布；
5. 对全部残基×状态假设做Benjamini-Hochberg FDR；
6. 报告11个可评估系列的相关方向一致性和series-bootstrap CI；
7. 未通过FDR的信号只能称探索性线索，不进入候选总分。

附加稳健性控制在主结果产生后冻结：对全部104个结构特征同时回归掉系列固定效应以及MW、logP、HBD、HBA、TPSA、转动键、芳环数、FractionCSP3和重原子数，再重复相同系列内置换与全假设BH-FDR。该控制不替换主分析，只检验显著信号是否可能由简单理化性质驱动。

## 预注册结论规则

- `q<0.05`且至少7/11系列同向：可称“跨系列静态结构关联”；
- `q>=0.05`：结论为“当前静态pose不支持单残基普适效力标志”，并转向多残基动态协同假设；
- 不根据结果删状态、残基或系列。
