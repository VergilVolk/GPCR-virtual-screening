# PACER-DC 动态编码器选择与近期成果路线

更新日期：2026-09-19

## 1. 现在已经得到的结果

我们在同一批公开 M4–iperoxo–MK-97 GaMD 数据上，用 6 条独立 replica 做了逐条留出比较。训练和标准化只使用 5 条轨迹，第 6 条轨迹只用于测试；轨迹帧没有被随机拆分到训练集和测试集。

| 方法 | 留出轨迹 lagged R² | 跨 replica 状态 JSD | 解释 |
|---|---:|---:|---|
| PCA-10 | 0.416 | 0.281 | 普通构象方差基线 |
| tICA-5 | 0.749 | 0.490 | 能提取慢模态，但状态分布较依赖 replica |
| VAMP-5 | 0.750 | 0.488 | 相比 PCA 明显提高动力学预测，但未优于 tICA |

VAMP 相对 PCA 的平均 lagged R² 增量为 0.334，6/6 个留出 replica 均改善，分层 bootstrap 95% CI 为 [0.287, 0.378]，精确双侧符号翻转检验 p=0.03125。VAMP 相对 tICA 的增量仅为 0.001，95% CI 为 [-0.001, 0.003]，不能认为有实质提升。

这个结果证明：当前口袋轨迹中存在可跨 replica 复现的慢动力学信号。但它不能证明这些慢模态对应 PAM 功能，因为全部 6 条轨迹来自同一个 PAM、同一个正构探针和同一种复合物。

## 2. OneProt-MD 是否作为主干模型

结论：暂不作为主干，只保留为可选的冻结外部基线。

原因：

1. 官方实现依赖 Apptainer/CUDA、MDGen 子模块和外部 checkpoint，源码中仍包含作者集群的硬编码路径，不能直接在本项目环境中推理；
2. 输入是蛋白轨迹，未显式编码 ACh、PAM 及其接触关系；全局时间和序列池化可能稀释 M4 别构口袋的局部变化；
3. 预训练目标主要对齐蛋白身份及多模态表征，不保证保留同一个 M4 在不同配体条件下的细微差异；
4. 即使成功运行，也必须在逐分子或逐 chemotype 外部留出中优于 tICA/VAMP 和可解释差分端点，才能成为算法贡献。

因此，不能在汇报中把 OneProt-MD 写成已经确定的 backbone。准确表述应为“候选预训练轨迹编码器”。

## 3. 当前应采用的主方法

PACER-DC 的核心不是某一个编码器，而是四上下文的配对设计：

1. M4 + candidate + ACh；
2. M4 + candidate；
3. M4 + ACh；
4. apo M4。

先用可解释端点建立功能差分：

- `candidate+ACh - ACh-only`：ACh 依赖协同变化；
- `candidate-only - apo`：候选物自身的激活样变化；
- 两个含候选物体系中的口袋滞留和接触：结合兼容性；
- replica 一致性和置信区间：不确定性。

随后在完全相同的外层切分中比较 PCA、tICA、VAMP、SPIB 和可行时的 OneProt-MD。编码器只有在留出 chemotype 上带来稳定增量时才进入主模型。Triplet 微调必须等多个 PAM chemotype、ago-PAM 和实验非活性/无功能结合对照齐备后再做。

## 4. 最近能形成的硬成果

第一项成果是“动态表示 benchmark”：现已完成 PCA/tICA/VAMP 的防泄漏比较，证明慢模态比普通方差更可预测，但 VAMP 未超过简单 tICA。

第二项成果应是“四上下文最小闭环”：先完成 LY2119620、compound-110、CM00717 和 CM00734 的短轨迹 QC，再计算手工双差分与 tICA/VAMP 双差分。它回答的是四上下文是否提供增量，而不是直接宣称发现新 PAM。

第三项成果是“候选优先级”：只把通过结合门控、动态差分方向一致且内在激动风险较低的分子称为计算优先候选；无湿实验时不称为已发现 PAM。

## 5. 明确停止的路线

- 不再用窗口数扩大有效样本量；独立单位是分子和 replica；
- 不用 2–4 个分子的 AUC 证明模型有效；
- 不再以训练集聚类分离或单一体系重构结果声称功能预测；
- 不因模型名称更新就跳过 PCA/tICA/VAMP 和手工端点；
- 不在四上下文尚未完成前进行正式 triplet 微调。
