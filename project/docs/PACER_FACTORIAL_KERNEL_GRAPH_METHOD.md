# PACER-FKG：四上下文动态的分布交互与多结构残基图

更新时间：2026-09-27

## 1. 当前最小可行算法

PACER-FKG 不逐帧配对独立 MD，也不在少量药理标签上训练大型网络。流程为：

`四上下文 MD → 冻结 Geom2Vec 残基表征 → 轨迹分布核均值 → 2×2 交互量 → 多结构残基图传播`

四个体系分别为无配体 `0`、仅 ACh `A`、仅候选物 `C`、ACh 与候选物共存 `C+A`。核心输出为：

- ACh 依赖协同：`ΔINT = μ(C+A) - μ(A) - μ(C) + μ(0)`；
- 无 ACh 自激活：`ΔAGO = μ(C) - μ(0)`；
- 条件性候选物效应：`ΔPAM = μ(C+A) - μ(A)`。

其中 `μ` 是轨迹帧分布在特征核空间中的均值，不是任意两帧的差。因此不同体系的帧不需要、也不允许伪装成一一对应。

## 2. 为什么比现有架构更合适

1. **解决轨迹不配对问题**：独立 MD 的第 20 帧与另一体系第 20 帧没有物理对应关系，分布比较避免了错误逐帧相减。
2. **适应小样本**：第一阶段没有可训练的大型 attention/MLP，减少从少数配体记住 chemotype 的风险。
3. **区分 PAM 与内在激动**：`ΔINT` 和 `ΔAGO` 是两个独立轴，compound-110 作为 allosteric agonist 压力测试，不能再与纯 PAM 混成一个分数。
4. **保留可解释性**：先得到每个残基的交互统计量，再沿实验结构定义的残基图平滑，可定位从胞外别构口袋到正构核心和胞内开关的传播区域。
5. **可证伪**：稳定核心阴性区若与机制区同幅升高，或不同 replica 不一致，算法直接不通过。

## 3. 口袋不再由单一 docking pose 定义

当前结构先验来自三种 PAM 复合物和一个变构激动剂对照：

- 7TRP：LY2033298；
- 7TRQ：VU0467154；
- 7V68：LY2119620；
- 7V6A：compound-110，作为变构激动剂对照；
- 7TRK / 7TRS：iperoxo / ACh 正构口袋。

三种 PAM 在 4.5 Å 内共同支持的核心残基为：

`Y89, Y92, I93, G96, F186, L190, N423, Q427, D432, W435, S436, Y439`

compound-110 相对 PAM 共识口袋的扩展包括：

`C185, Y416, M419, V420, S428, C429, I430, P431`

这两个区域将分别检验 PAM 共识耦合和内在激动相关的深部延伸，不能据此直接宣称因果机制。

## 4. 已完成的真实性检查

- 多结构图：270 个受体残基、1,304 条主链或跨结构重复出现的空间边；
- 核统计使用去除自相似对角项的无偏 U-statistic；
- 合成数据单元测试 3/3 通过：能识别非加和交互、能将自激活与交互分开、结果不依赖帧顺序；
- 冻结合成分布基准（100 seeds）中，均值改变时核方法与线性差分都能区分信号；在“均值保持、仅分布形状改变”的非线性交互中，核统计相对无交互对照的 AUC 为 `0.9966`，线性均值差仅为 `0.5973`。该数字只验证估计器能捕获预设分布变化，绝不是药理数据性能；
- 真实 compound-110 R1/W0 五帧烟雾测试可运行；
- 旧的 ICL3 边界“distal control”出现很高伪信号，说明它受柔性/构建边界污染，不适合作为唯一阴性对照；
- 按七套实验结构自动选择的稳定核心对照，`ΔINT` 无偏平方统计量为 `0.0885`；PAM 共识口袋为 `0.1042`，compound-110 扩展区为 `0.1996`，胞内微开关区为 `0.2658`。

最后一组数字只有一个 replica、五个抽帧，属于方法烟雾测试，**不能**解释为 compound-110 的功能机制或模型性能。它只说明新方法能够暴露局部差异，也能识别不合格阴性区域。

## 5. 最短验证路线与基线

先在已有 R2/R3 轨迹上运行，不重跑 MD：

1. 冻结 Geom2Vec 提取 R1–R3 全窗口；
2. 以 replica 为独立单位，做 block bootstrap；帧只能是轨迹内样本，不能增加独立样本量；
3. 比较五类基线：OneProt、原始几何距离、Geom2Vec 全局均值、固定区域线性均值、无图核统计；
4. 完整模型仅比“无图核统计”多一个冻结的多结构图传播步骤；
5. 在 LY2119620（纯 PAM）、compound-110（变构激动剂）和 CM00734（实验非活性近邻）上做方向性压力测试；
6. 采用 leave-chemotype-out，禁止按测试配体调整口袋、核带宽或残基权重。

晋级条件：跨 replica 方向一致、机制区相对稳定核心对照有特异增益、`ΔINT/ΔAGO` 能按预注册方向区分药理对照，并且完整模型稳定优于上述基线。未满足时，只能报告负结果，不能称为 PAM 预测器。

## 6. 暂不采用的高成本方案

- 直接训练 residue attention / Transformer：当前独立配体数不足，容易把帧数误当样本数；
- VAMPNet/SPIB 作为主预测头：适合学习单体系慢模态，但不能自动提供跨配体 PAM 功能标签；
- 继续调 OneProt-MD 最终全局表示：已有跨 replica 失败证据；
- 逐帧 triplet：独立轨迹没有配对帧，且会放大时间自相关。

Triplet 微调只保留为第二阶段：输入应为经 replica 汇总后的低维 FKG 签名，且必须有足够的独立 chemotype 与困难负样本。
