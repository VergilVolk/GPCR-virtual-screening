# PACER-FS：面向新药化系列的 M4 PAM 三锚点功能效力适配

> 冻结版本：v1.0，2026-08-29  
> 证据等级：当前内部 benchmark 最强、具有系列 bootstrap 显著性；**尚无独立外部同协议验证，不称全球 SOTA**。

## 1. 解决的不是“结合”，而是新系列中的功能效力排序

M4 PAM 的功能 pEC50 同时包含两类变化：

`y(s, x) = μ_s + f(x) + ε`

- `μ_s`：文献、assay、细胞系统和 chemotype 系列共同造成的基线偏移；
- `f(x)`：同一系列内部由结构变化驱动的相对 SAR；
- `ε`：实验噪声、activity cliff 和未观测 probe/state 条件。

普通绝对 QSAR 把二者混在一起学习。当一个来源/系列整体留出时，模型容易把
`μ_s` 的来源差异误认为可迁移结构规律。PACER-FS 将“排序”和“数值标定”拆开。

## 2. 冻结算法

### 2.1 系列内 SAR 头

训练集中，对每个来源组件 `s` 做 `y_centered = y - mean(y in s)`，使用固定
ECFP4、9 个理化描述符和低容量正则化 LightGBM 预测 `y_centered`。外层目标
系列的任何标签都不参与拟合。

### 2.2 三锚点最小实验设计

另一个固定绝对 QSAR 只用于选择实验锚点。对新系列全部候选按零样本预测排序，
选择 25%、50%、75% 分位的 3 个分子。该步骤不读取目标标签，目的是覆盖预期
效力动态范围。后续严格比较表明 predicted-span 的系列偏移绝对误差为 0.219，
随机三锚点为 0.226，差值 -0.007 的系列 bootstrap 95% CI 为
`[-0.108,+0.109]`；纯多样性选择数值为 0.216。因 CI 跨零，当前不能声称
predicted-span 优于随机；它只是冻结、可复现的预算策略，不是已验证的性能创新。

### 2.3 绝对效力标定

得到 3 个真实功能 pEC50 后：

`μ_new = mean(y_anchor - f(x_anchor))`

`pEC50_hat = f(x_query) + μ_new`

常数平移不改变系列内排序，但使输出回到可解释的 pEC50 尺度。没有 3 个真实
功能标签时，只允许输出相对优先级，不把分数称为已校准 pEC50。

### 2.4 双通道 ΔSAR 扩展

可选扩展从历史系列学习有方向的分子对 `ΔpEC50`，利用 3 个锚点扰动查询排序。
为防止 ΔSAR 破坏剂量尺度，强制扰动在查询批次中均值为零：

`delta_rank = DeltaSAR(x | anchors) - mean(DeltaSAR - base)`

该扩展在唯一 2022+ 系列有探索性收益，但在 11 系列总体上只比中心化核心提高
0.005，CI 跨零且最差系列略恶化，因此不是 v1.0 默认主模型。

## 3. 严格评价协议

- 数据：430 个唯一 M4 PAM 功能效力分子；主 few-shot 评价使用 11 个 `n>=12`
  来源组件。
- 外层：leave-one-source-component-out；完整目标组件不参与特征选择、模型训练
  或参数选择。
- 预算：3 个 label-free predicted-span 锚点；指标只在剩余查询分子上计算。
- 主指标：逐系列 Spearman 的宏平均、最差系列、正相关系列数、MAE。
- 统计：按系列而非按分子 bootstrap，避免大系列支配置信区间。

## 4. 冻结结果

| 方法 | macro Spearman | worst | 正相关系列 | macro MAE |
|---|---:|---:|---:|---:|
| 同架构绝对 QSAR | 0.199 | -0.157 | 10/11 | 0.453 |
| **PACER-FS 系列中心化** | **0.263** | **-0.005** | 10/11 | **0.443** |
| 双通道 ΔSAR（探索性） | 0.268 | -0.041 | 10/11 | 0.441 |

中心化相对绝对 QSAR 的宏平均 Spearman 增益为 `+0.064`，系列 bootstrap 95% CI
`[+0.017,+0.113]`，改善概率 99.65%。MAE 改善的 CI 跨零，不作为主要成功结论。

12 组固定 LightGBM 参数中 11 组取得正宏平均增益，中位增益 `+0.050`。仅未见
Murcko 骨架时为 `0.254→0.295`；再限制最近训练邻居 Tanimoto `<0.70` 时为
`0.218→0.249`。收益不由完全相同骨架泄漏解释，但严格远域最差系列仍会失败。

自由地让内层从多种 few-shot 适配器中挑选并没有成功：严格嵌套结果为
`0.175 vs 0.184`。该负对照表明小样本下复杂方法选择本身会过拟合，支持固定
低方差分解模型。

## 5. 时间压力测试

在唯一可评价的 2022+ 系列中，中心化单独没有改善（`0.148→0.107`）；开放 3 个
锚点后，均值守恒 ΔSAR 的排序为 `0.303`（绝对通道）和 `0.316`（中心化通道）。
这只是一个系列的回顾性探索结果，不是独立前瞻验证，也不能计算稳定的跨系列 CI。

## 6. 适用域与拒绝规则

1. 目标必须是同一 assay/probe 定义下、可视为一个药化系列的候选集合。
2. 默认需要至少 12 个候选和 3 个实测功能锚点；少于该规模不报告系列 Spearman。
3. 无锚点时只报告相对 SAR 分数；不报告“已校准效力”。
4. 候选远离训练化学域时明确标记探索性；当前数据不能给出可靠单分子误差条。
5. 该模型在已知 PAM 内部预测 potency，**不判断一个未知分子是否为 PAM**。
6. PAM 身份必须由含正构探针的功能 assay、候选单独加药对照和浓度矩阵确认。

## 7. 创新点与边界

- 将跨文献效力偏移与可迁移的系列内 SAR 显式因子化；
- 用 3 个 label-free 锚点定义最小功能实验集，但不声称锚点策略已优于随机；
- 将相对排序通道与绝对 pEC50 标定通道分离；
- 用完整系列留出、参数区域、化学域和时间测试共同证伪复杂适配器。

当前可称“PACER benchmark 上最强的内部新系列方法”，不能称领域全球 SOTA。
升级需要新收集、从未参与开发的 M4 PAM 系列进行预注册 3-anchor 前瞻评价，或
公开同协议外部 benchmark 的直接比较。
