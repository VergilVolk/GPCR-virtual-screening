# PACER-FS v0.2 预注册：可靠性门控的三锚点新系列适配

状态：**在首次运行 v0.2 结果前冻结**  
日期：2026-08-29

## 科学问题

在一个从未进入训练集的 M4 PAM 化学系列中，允许测量 3 个分子的功能
pEC50。目标是在剩余同系列分子中提高效力排序，同时避免不可靠的跨系列
ΔSAR 造成负迁移。

## 固定协议

- 外层：leave-one-series-out；目标系列完全不参与基础模型和 ΔSAR 模型拟合。
- 锚点：只根据零样本基础模型预测，从预测分布的 25%、50%、75% 分位选取；
  选择时不读取真实标签。
- 预算：固定 3-shot。
- 评价：同一查询集上的宏平均 Spearman、最差系列 Spearman、正相关系列数、MAE；
  置信区间按系列 bootstrap。

## 冻结算法

1. 跨训练系列学习有方向的分子对 ΔpEC50 模型。
2. 每个查询分子分别由 3 个锚点重建绝对 pEC50，Tanimoto 相似度三次方加权。
3. 在 3 个已测锚点内部做 leave-one-anchor-out 重建；与零样本基础模型在同一
   锚点上的 MAE 比较，得到系列级可靠性：

   `r_series = sigmoid((MAE_base - MAE_delta) / 0.15)`

4. 对每个查询计算 3 个锚点重建值的加权标准差 `sigma_q` 与最大锚点相似度
   `s_q`，得到局部门控：

   `r_local = exp(-(sigma_q / 0.50)^2) * clip(s_q / 0.50, 0, 1)`

5. 最终预测：

   `p_final = p_base + 0.60 * r_series * r_local * (p_delta - p_base)`

所有常数均在读取 v0.2 输出前冻结。若排序不改善，则 v0.2 判定失败，不根据
外层标签追加调参。

## 成功判据

主要判据：相对同查询集基础模型的宏平均 Spearman 增益，其按系列 bootstrap
的 95% CI 下界大于 0。次要判据：MAE 降低，且最差系列不恶化。未达到主要
判据时不得使用“SOTA”或“验证成功”。
