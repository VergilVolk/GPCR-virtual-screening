# PACER-M4 摘要素材库

> 本文件提供摘要写作的稳定素材，不代表所有数字已经通过最终 benchmark。带 `[待验证]` 的内容不得写成确定结论。

## 1. 背景句

正性别构调节剂通过增强内源性正构激动剂的受体响应，为 GPCR 亚型选择性和生理时空依赖调控提供了重要机会。然而，传统虚拟筛选和多数生成模型主要优化结合亲和力，难以刻画依赖正构探针、受体状态和信号通路的功能协同性。

## 2. 科学问题句

本研究关注一个方法学问题：能否从候选分子、正构探针、实验上下文及受体变构耦合结构中联合学习人源 M4 PAM 功能效力，并在新骨架、新药化系列和时间外推条件下获得可靠泛化？

## 3. 方法句

我们构建 PACER-M4，一个以严格系列外推和可证伪结构证据为核心的 M4 PAM 候选提出框架。框架比较 ligand-only、预训练分子模型、差分 SAR、三受体状态 docking/IFP 和嵌套结构专家，淘汰不能稳定泛化的模块；随后对受控片段与神经生成路线进行适用域审计，以 ACh 状态口袋相容性、药化性质和受限新颖性进行 Pareto 候选选择。

## 4. Benchmark 句

我们基于人工清洗的人源 M4 PAM 功能数据建立 M4-PAM-Benchmark v1.0，设置分子、骨架、整药化系列和时间外推四级隔离，并使用实验确认非活性物、activity cliffs 和外部结构筛选数据评价功能预测、早期富集和模型校准。

## 5. 已冻结结果句

- 我们整理 430 个具有精确 ACh/calcium 功能效力的人源 M4 PAM，构建 12 个整药化系列留出和 2022+ 伪前瞻测试，并建立含 93 个 activity cliffs 的近邻对基准。
- 最强 ligand-only Pareto baseline 的 macro Spearman 为 0.199–0.207；Chemprop 和 ChemBERTa 未超过 LightGBM。
- PACER-FS 将来源组件的效力基线与系列内 SAR 分解，在共同 11 系列三锚点协议上把 macro Spearman 从 0.199 提至 0.263，按系列 bootstrap 的增益 95% CI 为 `[+0.017,+0.113]`；12 组固定参数中 11 组取得正增益。
- ACh 状态低维 IFP 可独立达到 macro Spearman 0.191，但嵌套静态结构融合由 0.207 降至 0.151，表明静态口袋证据不能直接转化为跨系列功能效力增益。
- 在约 11.8 万分子的外部 M4R active/decoy 基准中，单 PDB Vina 虽有 ROC-AUC 72.53%，EF(0.5%) 仅 0.778，显示全局判别与真正早期富集明显脱钩。
- 2022+ 主系列 Spearman 为 -0.028；固定适用域门槛和局部近邻不确定性也未能恢复稳定外推。
- 受控片段、LSTM、GPT 和 masked diffusion 分别产生 2954、306、16 和 0 个有效输出；神经生成物全部落在当前证据域外。
- 200 个受控片段候选完成 ACh 状态结构门控，最终得到 24 个、覆盖 20 个 Murcko 骨架的可实验检验假设；效力预测和 docking affinity 未进入人为加权总分。

## 6. 可用摘要草案

正性别构调节剂的功能效力依赖正构探针、受体状态和变构协同性，难以由静态结合亲和力直接推断。我们建立 M4-PAM-Benchmark，整理 430 个 ACh/calcium 条件的人源 M4 PAM，采用整药化系列、activity-cliff 与时间外推评价 ligand-only、预训练分子、差分 SAR 和三状态结构模型。针对跨文献效力偏移，我们提出 PACER-FS，将系列固定效应与系列内 SAR 分解，并以 3 个 label-free predicted-span 锚点恢复绝对效力尺度；在共同 11 系列上 macro Spearman 从 0.199 提至 0.263，增益 95% CI 为 `[+0.017,+0.113]`。ACh 状态 IFP 提供独立结构信号（0.191），但嵌套结构融合降至 0.151，说明静态口袋证据不能直接替代功能效力。随后，我们不使用 docking affinity 作为效力总分，而对生成分子执行适用域、口袋相容性、药化性质和多样性的 Pareto 审计，得到 24 个覆盖 20 个 Murcko 骨架的可实验检验假设。本研究给出一个将相对 SAR、最小功能标定与可证伪结构门控分离的 M4 PAM 计算范式。

## 7. 边界句

本研究输出的是经严格回顾性和伪前瞻验证的可实验检验候选，而非湿实验确认的 PAM；功能验证仍是判断新分子真实协同性和内在激动活性的最终标准。

## 8. 禁止写入摘要的表述

- “对接证明候选是 PAM”；
- “预测概率 0.99 证明候选有效”；
- “AUC 1.0”但样本只有少量阳性或亚位点由同一数据定义；
- 未完成独立验证时声称 SOTA；
- 把 Miao/ASD 大型结构筛选标签直接当统一功能效力 ground truth；
- 把生成数量或新颖性当作药效提升。
