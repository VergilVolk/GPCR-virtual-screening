# PACER-M4 动态验证协议（预注册 v1.0）

## 目的与边界

静态 docking 只能提出结合姿势，不能证明 PAM 功能效力。本模块检验的对象不是“结合更紧”，而是候选在 **ACh—M4—Gi** 三元/四元体系中是否稳定支持从别构口袋到正构口袋和胞内效应器界面的耦合网络。

生产级 MD 尚未在当前 CPU 工作站上执行；下列协议是后续 GPU/计算集群上的冻结验证设计。任何短时间 CPU smoke test 只检查系统和代码，不得进入生物学结论。

## 对照体系

每个体系至少 5 个独立重复、不同初速度；生产阶段建议每重复 200 ns，且在分析前冻结：

1. ACh—M4—Gi，无 PAM（基线）；
2. ACh—M4—Gi + VU0467154（阳性结构对照）；
3. ACh—M4—Gi + LY2033298（不同 chemotype 阳性对照）；
4. iperoxo—M4—Gi + 两个已知 PAM（probe-dependence 对照）；
5. 至少 2 个严格实验非活性近邻（阴性对照）；
6. 每轮候选不超过 12 个，并与最近邻阳性采用同一参数化流程。

没有第 2–5 项对照的候选 MD 不构成验证。

## 系统准备

- 初始受体：7TRS ACh 状态；将已知/候选 PAM 的结构门控姿势映射到 ECV 别构口袋；
- 受体嵌入 POPC/胆固醇膜，显式水，0.15 M NaCl，周期性边界；
- 保留 ACh、Gi 蛋白和关键结构水；修补缺失环区但对远离口袋的低可信区施加温和约束；
- 蛋白/脂质使用同一 CHARMM36m 或 Amber 系列，所有小分子统一 CGenFF/GAFF2 参数化与电荷方法；
- 逐步最小化、NVT/NPT 平衡并释放约束；记录质子化、手性、互变异构和参数罚分。

## 预注册动态终点

不使用单一“MD 总分”。每条轨迹输出以下可审计证据：

- PAM pose retention：相对初始姿势 RMSD、口袋逃逸比例；
- interaction occupancy：关键残基接触/氢键/水桥占有率及重复间置信区间；
- orthosteric stability：ACh 构象与正构接触保持率；
- coupling network：PAM 接触节点到正构口袋和 Gi 界面的动态互信息/相关网络路径；
- activation geometry：TM6 胞内端位移、NPxxY、DRY、PIF microswitch 分布；
- probe dependence：同一 PAM 在 ACh 与 iperoxo 条件的上述特征差；
- replicate stability：重复间方差、有效样本量和收敛诊断。

## 判定规则

候选仅在以下条件下晋级为“动态支持的 PAM 假设”：

1. 不发生持续口袋逃逸；
2. 至少一种 coupling-network 指标相对无 PAM 基线向两个阳性对照方向移动；
3. 该移动在多数独立重复中一致，且阴性近邻不出现同等变化；
4. 不以 Vina、MM/GBSA 或单轨迹均值替代上述对照；
5. 所有阈值在候选轨迹解盲前由阳性/阴性对照冻结。

## 与最终算法的关系

MD 是昂贵的末级机制验证器，不是 430 分子训练集的标签制造器。最终 PACER-M4 按以下次序工作：生成与药化过滤 → 适用域与近邻溯源 → ACh 状态结构门控 → 多目标 Pareto/多样性选择 → 对照化 MD → 湿实验功能验证。只有最后一步能确认 PAM 效力、协同性、probe dependence 与内在激动活性。
