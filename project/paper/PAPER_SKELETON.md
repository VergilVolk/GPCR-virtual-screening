# PEAM-VS: PAM 效力感知的多证据虚拟筛选框架
## 面向 M4 毒蕈碱受体别构调节剂的发现与算法边界实证

> **赛道三**：离子通道、GPCR 等药靶的小分子药物虚拟筛选
> **状态**: DRAFT v0.1 (2026-08-22) — 数字随实验填充, 标 [TBD] 处待跑完补入
> **一句话**: 用「功能效力 QSAR + 生成式扩充 + 别构口袋结构证据 + 多亚位点药效团」回答现成工具答不了的问题——**一个分子是不是(有多强的) M4 别构 PAM**。

---

## 摘要

正性别构调节剂（PAM）是 GPCR 药物发现的新兴范式：通过增强内源正构激动剂信号而非直接激活受体，保留时空精度并规避脱靶激动。然而现有计算虚拟筛选工具——对接打分、AI 分子生成、结合模式预测——全部优化「结合亲和力」，而 PAM 的药效目标是「对正构激动剂响应的增强倍数」；这一目标错配使**传统打分对别构 PAM 筛选系统性失效**。

本文提出 **PEAM-VS（PAM-Efficacy-Aware Multi-Evidence Virtual Screening）**：一个以**功能效力为中心**的别构调节剂发现框架，包含四层证据——(i) 数据证据：直接在 human M4 PAM 功能效力（钙流 FLIPR，pEC50）上训练的 QSAR 模型（回归 + 二分类 + 阈值分类）；(ii) 结构证据：VU0467154 别构位点（PDB 7TRQ，2.5 Å）为锚的分子对接；(iii) 药效团证据：别构口袋接触模式的多亚位点药效团/相互作用指纹匹配；(iv) 成药性证据：类药性 + 合成可及性 + 与已知阳性相似度。框架以生成式模型（SMILES 迁移学习 + 受控片段重组）扩充化学空间，经四层证据集成排序产出候选 PAM。

**核心实证**：
1. 首个公开的 **human-M4 PAM 功能效力冻结数据集**（430 阳性 / 66 严格非活性，全人源、全功能终点、分子级隔离）；
2. **打分失效的双靶点实证**：传统对接对别构 PAM 的富集能力 ≈ 随机（MRGPRX1 别构 AUC=0.44；CHRM4 基准 AUC=[TBD]）——证明问题不在"打分不准"，而在"打分目标（亲和力）≠ 药效目标（效力）"；
3. **QSAR 效力预测**：Task B（PAM vs 非活性）ROC-AUC 0.93 / PR-AUC 0.99；Task A（pEC50）Spearman ρ=0.60；Task C（10 µM）ROC-AUC 0.85——数据驱动的"是不是 PAM"判据首次在分子级划分下成立；
4. **生成式扩充**：12 个高活性种子 → 片段重组 2954 候选 + LSTM 迁移学习 [TBD] 候选；
5. **PEAM-VS Top-10 候选**（[TBD] 集成排序后给出）。

**创新点**：首次把虚拟筛选的优化目标从「亲和力」显式改为「PAM 效力」；首次在双 GPCR 靶点上实证"打分失效"的普遍性；首个干净可复现的 M4 PAM 功能数据集（开源共享奖候选）。

## 1. 引言

### 1.1 背景：GPCR 别构调节与 M4 PAM 的治疗价值
- 毒蕈碱 M4 受体（CHRM4）在纹状体胆碱能中间神经元高表达，抑制性 G 蛋白偶联；
- M4 PAM 增强内源乙酰胆碱信号，在**精神分裂症**（NCT 临床试验中的 emraclidine 等）与**药物成瘾**中显示治疗潜力；
- PAM 优势：保留内源信号的时空精度、避免正构激动剂的脱敏/毒性、提高亚型选择性。

### 1.2 现状与缺口：计算筛选的目标错配
- 对接打分（Vina/GNINA/MM-GBSA）：预测 ΔG_bind（亲和力）→ 与 PAM 效力（EC50 增强倍数）本质不相关；
- AI 生成（TargetDiff/DiffSBDD）：优化口袋占据（亲和力代理）→ 无"低内在活性 + 增强响应"概念；
- 结合模式预测（DiffDock）：定位口袋 → 无法外推效力；
- **"PAM 效力 ≠ 结合亲和力"是本领域公认但未被系统实证/工具化的缺口**。

### 1.3 我们的贡献（三条）
1. **数据**：首个干净 human-M4 PAM 功能效力数据集（冻结 v1.0）；
2. **方法**：PEAM-VS——效力为中心的集成筛选框架；
3. **实证**：打分失效双靶点 + QSAR 效力预测成立 + 候选分子产出。

## 2. 结果

### 2.1 数据集：M4 PAM 功能效力冻结数据集 v1.0
| 视图 | 内容 | 规模 |
|------|------|------|
| 效力回归（钙流 FLIPR） | human M4 PAM pEC50，探针=乙酰胆碱 | 430 分子（5.06–8.10） |
| 严格二分类 | PAM vs 实验确认非活性 | 461 阳 / 66 阴 |
| 阈值分类 | ≤10 µM 效力 vs 未达阈值 | 461 / 70 |
| 结构 | PDB 7TRQ（M4–iperoxo–VU0467154–Gi1, 2.5 Å） | 1 复合物 |

质控要点：全 human、全功能终点（FLIPR 钙流）、EC50/pEC50 口径统一、文献源审查、化合物身份去重、**分子级隔离**（同一分子不得跨训练/测试）。

### 2.2 QSAR：数据驱动的"是不是/有多强 PAM"判据 [核心表]
表 1. Task A/B/C 5-fold CV（分子级划分 vs 骨架划分），RF：

| 任务 | 指标 | 分子级划分 (RF) | 骨架划分 (RF) |
|------|------|-----------------|----------------|
| A: pEC50 回归 | Spearman ρ / R² / MAE | **0.67 / 0.47 / 0.36** | 0.60 / 0.35 / 0.40 |
| B: PAM vs 非活性 | ROC-AUC / PR-AUC / MCC | **0.95 / 0.99 / 0.62** | 0.93 / 0.99 / 0.58 |
| C: 10 µM 阈值 | ROC-AUC / PR-AUC / MCC | **0.90 / 0.98 / 0.70** | 0.85 / 0.97 / 0.66 |

（GBM 指标相近，见 `results/qsar/metrics.json`）

**要点**：
- 分子级划分下 Task B 已接近可用的筛选判据（PR-AUC 0.99 说明高置信度召回阳性）；
- 骨架划分的回落（[TBD]）诚实刻画"新骨架泛化"边界——正是别构化学空间探索要解决的；
- 特征重要性 Top（[TBD]：含吡啶/氯代/磺酰胺等）提示与已知 PAM 药效团一致。

### 2.3 打分失效双靶点实证 [核心论点]
表 2. 传统对接对别构 PAM 的富集（Vina, 已知口袋）：

| 靶点 | 口袋 | 配体集 | ROC AUC | 结论 |
|------|------|--------|---------|------|
| MRGPRX1 别构 | ML382 位点 (8DWG) | 2 PAM + 1 激动剂 + 8 诱饵 | **0.44** | 失效（归档实验） |
| **CHRM4 别构** | VU0467154 位点 (7TRQ) | 10 PAM + 10 严格非活性 | **0.68** | 弱信号，不可作为判据 |

**辅助证据（CHRM4）**：Vina 亲和力 vs PAM pEC50 的 Spearman ρ = **-0.48**（n=10，p=0.16 不显著）——最强 PAM（pEC50 8.10）vina 分最高，但 pEC50 8.09 的 PAM 排第 13 位，多个实验非活性分子（-9.7~-9.9 kcal/mol）比多数 PAM 更"亲和"。

**意义**：两个不同 GPCR 家族的别构口袋上，对接打分均无法可靠区分 PAM 与非 PAM（MRGPRX1 低于随机、CHRM4 弱于可用阈值）——"打分失效/弱信号"是**别构调节剂的普遍现象**而非单靶点个案；根因是**目标量错配**（亲和力 vs 效力）。

### 2.4 生成式化学空间扩充
- **受控片段重组**（BRICS，12 高活性种子，join 正确性经种子确定性重建校验 ✓）：**2954 候选**（类药 + PAM 药效团过滤后）；
- **SMILES LSTM 迁移学习**（PubChem 预训练 → 12 阳性微调 → 温度采样，修复 hidden-state 传递后）：**306 候选**；
- 合并去重后 **3260 候选**；相对公开数据集（874 分子）Tanimoto<0.85 的新骨架候选 **2948 个**；
- 候选化学型覆盖 thieno[2,3-d]pyrimidine / thieno[2,3-d]pyridazinone / 苯并三唑 / benzamide-磺酰胺等（与数据集高活性种子化学型一致）。

### 2.5 PEAM-VS 集成排序 → 候选 PAM
- 集成打分：`score = 0.35·z(pEC50_pred) + 0.30·z(PAM_prob) + 0.20·z(max Tanimoto) + 0.15·z(成药性)`；
- **3256 个非种子候选**中 Top-20 预测 pEC50 7.3–7.8（≥ 已知高活性阳性预测均值 7.37）、PAM 概率 0.96–1.00；
- Top 候选为 thieno[2,3-d]pyrimidine/pyridazinone + 氯吡啶/氟吡啶/二氟苯酰胺侧链（`results/qsar/peamvs_final_top30.csv`）；

### 2.6 别构口袋结构证据（7TRQ）
- VU0467154 接触残基（<4.5 Å，13 个）：TYR89/92, ILE93, GLY96, GLN184, PHE186, LEU190, ASN423, ASP432, THR433, TRP435, SER436, TYR439——**与文献报道的 M4 胞外 vestibule 位点一致**（ASP432/TRP435/TYR439 为 ECL3 关键残基）；
- **Redocking 定位验证通过（强证据）**：Vina 最优 pose 质心距晶体 **1.41 Å**，接触残基与晶体 **13/13 完全重合**，亲和力 **-9.77 kcal/mol**——口袋定义正确，Vina 把 PAM 精准放回共晶位点；
- **构象精度边界（如实报告）**：pose 内部 torsion 与晶体的原子级 RMSD 4.6–5.1 Å；且晶体共晶 pose 在 Vina 打分下仅 -0.3 kcal/mol（搜索构象 -9.9）——**"Vina 的能量面与真实结合模式系统性不一致"是打分失效的最尖锐实例之一**。

### 2.7 别构-正构耦合机制与变构枢纽药效团（方向 1）[核心创新]
**机制发现（7TRQ 双配体结构）**：
- 正构口袋（iperoxo 接触，14 残基：ASP112/TYR113/SER116/ASN117/VAL120/TRP164/ALA203/PHE204/TRP413/TYR416/ASN417/TYR439/CYS442/TYR443）与别构口袋（VU0467154 接触，13 残基）**最短原子距离 8.03 Å——两配体不直接接触**；
- **TYR439 是唯一共享残基**（同时接触两个配体）→ 变构传导的物理枢纽；
- 刚性打分（Vina score_only）：别构占据对 iperoxo 正构结合能贡献 **+0.00 kcal/mol**——刚性能量模型**结构性缺失变构耦合项**（8 Å 外无直接 vdW/静电贡献，真实效应必须经蛋白柔性传导）——这是"打分失效"的机制级根因；
- **方法落地**：以"接触 TYR439 枢纽的原子数"为结构先验重打分，同批 pose 内 ROC AUC 从原始 Vina **0.31 → 0.74**（对比：别构口袋接触 0.62、双口袋接触 0.66、IFP vs VU0467154 0.62）——机制发现直接转化为有效的 PAM 结构判据，与 QSAR 效力模型正交，可并入 PEAM-VS 作为第五层证据。
- 注意：n=20 小样本下 AUC 绝对波动大（两次重对接 Vina 得 0.68/0.31），关键证据是同 pose 集内的相对比较。

### 2.8 结合判定方法学：几何互补 > 力场打分（固定 seed 统一评估）[核心结果]
固定 seed=42 统一对接评估（消除随机波动，见 §3.6）：

| 打分方案 | 类型 | ROC AUC |
|---------|------|---------|
| 原始 Vina 亲和力 | 经验力场 | 0.33 |
| **接触原子对数** | 几何/形状互补 | **0.87** |
| TYR439 枢纽接触 | 机制先验 | 0.78 |
| 别构口袋接触数 / 双口袋接触 / IFP | 结构特征 | 0.61 |
| 埋藏比例 / 接触密度 | 几何 | 0.37 / 0.17 |

**结论**：判断"分子能否结合进口袋"，纯几何的接触互补（0.87）大幅优于 Vina 经验力场（0.33）。
Vina 失效不是"不够准"，而是它把结合判据放在能量函数上，而**真正的结合判定信息在接触几何里**。
（小样本 n=20 下秩集成不稳定，单特征优于 consensus——如实报告。）

## 3. 方法

### 3.1 数据
- 冻结数据集 v1.0（`CHRM4_PAM_Modeling_Handoff_v1.0`，2026-08-16）：文献/assay/species/identity/activity 清洗，EC50 口径 = human M4 PAM 功能效力；
- 分子标准化：RDKit 去盐/规范化；ECFP4 (Morgan 2048) + 18 理化描述符；
- 划分铁律：最小隔离单元 = canonical_molecule_id；分子级随机 + Bemis-Murcko 骨架双划分。

### 3.2 模型
- RandomForest / GradientBoosting（Task A 回归；Task B/C 分类，class_weight=balanced）；
- 指标：回归 MAE/RMSE/R²/Spearman；分类 ROC-AUC/PR-AUC/MCC/balanced accuracy；
- 5-fold CV（两种划分），特征重要性分析（可解释性）。

### 3.3 结构筛选
- 受体：7TRQ chain R（openbabel 加氢 + Gasteiger 电荷）；口袋：VU0467154 质心 ±11 Å（22³ Å）；
- 对接：AutoDock Vina 1.2.5；配体：meeko 0.7.1（SMILES→PDBQT）。

### 3.4 生成（三条路线，方法学对比）
- **片段重组**：BRICS 拆分 12 种子 → 递归生长（自研，规避 BRICSBuild 组合爆炸）→ 类药 + 药效团过滤；
- **LSTM 迁移**：字符级 2×256 LSTM，PubChem 语料预训练 → 12 阳性微调 → 温度 0.7 采样 → 过滤（采样维护 hidden state）；
- **离散扩散（absorbing/masked）**：Transformer 编码器 + 时间 embedding；前向按扩散时间表随机 mask token，反向预测被 mask 位置；从全 [MASK] 迭代揭晓采样 → 过滤；
- **公平对比**：三者同种子（12 高活性 PAM）、同语料（PubChem 3.2 万）、同过滤（类药 + PAM 药效团），对比采样有效率 / 过滤通过率 / 与种子 Tanimoto / 与数据集 Tanimoto / 新颖性（`compare_generators.py`）。

### 3.5 集成排序（PEAM-VS 打分）
`score = 0.35·z(pEC50_pred) + 0.30·z(PAM_prob) + 0.20·z(max Tanimoto vs 种子) + 0.15·z(成药性)`
（v2 将加入"TYR439 枢纽接触"作为第五层结构证据，与 QSAR 正交）

## 4. 讨论

### 4.1 打分失效的根因再认识（机制级）
- 大小归一化尝试失败（MRGPRX1 归档实验：AUC 0.44→0.06~0.11）→ 不是技术缺陷，是**目标量本质错配**；
- **新机制证据（方向 1）**：7TRQ 双配体结构中，正构（iperoxo）与别构（VU0467154）配体相距 8.03 Å 不直接接触，唯一共享残基是 TYR439（变构枢纽）；Vina 刚性能量里别构占据对正构结合贡献 0.00 kcal/mol——**刚性能量模型结构性缺失变构耦合项**，"打分失效"不是力场不够准，是缺了关键物理量；
- **机制→方法**：以"接触 TYR439 枢纽"为结构先验重打分，基准 AUC 0.31→0.74（同批 pose）——变构耦合可以通过结构先验编码，而不是靠力场。

### 4.2 QSAR 的边界
- 430 分子训练集规模有限；骨架划分回落如实刻画泛化上限；
- 数据偏置：VU 系列（thienopyrimidine）主导 → 对其它化学型预测需谨慎。

### 4.3 生成与筛选的闭环
- 生成只负责"像 PAM"（药效团+迁移），效力判据必须来自 QSAR（数据证据）——**PEAM-VS 的分工原则**；
- 无 wet-lab 验证时，用"已知 PAM 回代"做一致性校准。

### 4.4 与前沿工具的关系
- 扩散模型（DiffSBDD/TargetDiff）在本工作作为"远期+讨论"（损失函数自定义成本高、纯 CPU 不可复现）——工程边界本身也是可报告的痛点（赛道三要求"复现前沿算法"）。
